# Muhammad Akhwan Nursidiq — Network Engineering Portfolio

Portfolio website untuk menampilkan profil, technical skills, pengalaman, project networking, dan sertifikasi.

## Struktur

```text
.
├── index.html
├── style.css
├── script.js
└── assets/
    ├── profile.jpg
    └── CV-Akhwan-Nursidiq.pdf
```

## Deploy ke GitHub Pages

1. Buat repository GitHub, misalnya `akhwannursidiq.github.io`.
2. Upload seluruh isi folder portfolio ini.
3. Pastikan `index.html` berada di root repository.
4. Buka **Settings → Pages**.
5. Pilih branch utama (`main`) dan folder `/root`.
6. Simpan, lalu buka alamat GitHub Pages repository.

## Catatan

Link project saat ini diarahkan ke halaman repositories GitHub. Setelah setiap project dibuat sebagai repository terpisah, ubah link `Lihat Repository` pada `index.html` ke URL repository masing-masing.
